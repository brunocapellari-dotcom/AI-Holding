# Principles

1. Evidence before promotion.
2. Provenance is mandatory.
3. Operational agents contribute; they do not self-certify.
4. Knowledge is versioned through supersession, not destructive overwrite.
5. Current validity and historical truth are different concerns.
6. Outcomes recalibrate confidence.
7. Shared knowledge is logically isolated by namespace/project policy.
8. Add infrastructure only when measured needs justify it.
