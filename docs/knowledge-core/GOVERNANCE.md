# Universal Knowledge Governance

The shared Second Brain uses logical isolation rather than separate knowledge databases per project.

## Required claim dimensions

- namespace
- project scope when applicable
- provenance and evidence
- epistemic status
- lifecycle status
- confidence
- temporal validity
- origin agent/run when generated operationally
- supersession link when replaced
- outcome feedback when the claim is testable

## Promotion authority

Operational agents cannot self-promote knowledge. Knowledge IA prepares candidates; Auditor IA validates and promotes under Control Plane authorization. Human approval remains mandatory for any policy-controlled material action.

## Temporal governance

Expired claims remain in history but are excluded from normal context retrieval. Superseded claims remain queryable for audit and historical reasoning. New claims should supersede old canonical claims rather than overwrite them.
