# Layout de extração

Dentro do monorepo de transição, `second_brain/` representa a futura raiz do repositório independente.

Estruturas lógicas: `vault/`, `graph/`, `ingestion/`, `claims/`, `validation/`, `provenance/`, `sources/`, `methods/`, `models/`, `events/`, `cases/`, `skills/`, `evaluations/`, `taxonomy/`, `schemas/`, `connectors/`, `tests/` e `docs/`.

Diretórios existentes não são movidos apenas por estética. Código e dados legados serão migrados por compatibilidade e reconciliação, preservando histórico e rollback.
