# Skills

Capacidades reutilizáveis e versionadas que agentes podem consumir sem duplicar regras entre projetos.

Skill não concede acesso. Cada execução continua sujeita ao Policy Service, MCP Gateway, identidade e sandbox. Skills devem declarar inputs/outputs, ferramentas necessárias, risco, efeitos colaterais, idempotência e evidência esperada.

Conhecimento de domínio consolidado não mora aqui: pertence ao Segundo Cérebro. Esta pasta contém procedimentos executáveis e contratos técnicos.
