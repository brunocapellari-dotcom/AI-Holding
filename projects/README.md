# Projects

Manifestos lógicos das unidades administradas pela Holding. Código das unidades continua nos respectivos repositórios; esta pasta não copia fonte nem conhecimento canônico.

Cada manifesto futuro deve referenciar project key/ID, repositório, subpath quando aplicável, owner agent, prioridade, nível máximo de autonomia, budgets, ambientes, critérios objetivos e integrações permitidas.

AgroLog MT, Inteligência Pecuária e Maritime Intelligence permanecem administráveis separadamente mesmo compartilhando o repositório AgroLogMT. Finance, Sports, Geopolitical Watch, WorldWar e outros projetos seguem a mesma regra de separação lógica.
