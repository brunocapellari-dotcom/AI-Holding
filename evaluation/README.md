# Evaluation

Avaliações objetivas da Holding e de seus agentes. Esta área reúne acceptance tests, avaliação de qualidade, regressão de políticas, segurança adversarial, independência de auditoria, factualidade do Hermes e critérios de promoção de autonomia A0–A6.

Uma avaliação nunca substitui o audit trail operacional. Resultados devem referenciar `project_id`, `agent_id`, `task_id`/`run_id` quando aplicável e produzir evidência reproduzível.

A Security Test Suite será consolidada nesta fronteira em conjunto com `security/`, cobrindo secret leakage, prompt/tool injection, privilege escalation, SQL injection, path traversal, SSRF, command injection, isolamento entre projetos, acesso não autenticado, webhook tampering e dependência comprometida.
